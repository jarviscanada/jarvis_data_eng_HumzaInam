# Credit Risk Scoring ML

## Overview
End-to-end credit default prediction project using the Home Credit Default Risk dataset.

## Setup
1. Create virtual environment
2. Install packages
3. Download Kaggle data into `data/`

## Notebook Order
1. 01_eda.ipynb
2. 02_preprocessing.ipynb
3. 03_feature_engineering.ipynb
4. 04_modeling.ipynb
5. 05_explainability.ipynb
6. 06_final_pipeline_and_documentation.ipynb

## Outputs
- Saved model in `models/`
- SHAP and PSI outputs in `reports/`
